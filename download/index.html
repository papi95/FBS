Link blocked? Use the copy on this page.

  1. Right-click the ZIP → Extract All → any folder, e.g. C:\FBS
  2. Run gpu_report.exe first. It should name your Intel HD 5500 and say hardware GPU.
  3. Run fbs.exe. Click a scene, press Space to take it live, drag the T-bar.
  4. Run render_project.exe to write proof PNGs into artifacts\frames\.
SmartScreen may warn the publisher is unknown — choose More info then Run anyway. These are local unsigned builds; nothing is installed.
